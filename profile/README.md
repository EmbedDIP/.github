# EmbedDIP

**Embedded Digital Image Processing on edge platforms.**

EmbedDIP collects the code, libraries, and examples for the Springer book series
*Embedded Digital Image Processing with Microcontrollers* by Cem Unsalan and Ozan Durgut (2026).
The projects cover acquiring images, processing pixels, filtering, morphology, neural networks,
and running image-processing ideas on resource-constrained hardware.

## Core Repositories

- [**embedDIP**](https://github.com/embeddip/embedDIP) — portable C/C++ digital image processing library for microcontrollers.
- [**examples-stm32**](https://github.com/embeddip/examples-stm32) — STM32 examples and support files.
- [**examples-esp32**](https://github.com/embeddip/examples-esp32) — ESP32 / Arduino example sketches.
- [**PyDIPLink**](https://github.com/embeddip/PyDIPLink) — Python UART image/video transfer tool for embedded devices.
